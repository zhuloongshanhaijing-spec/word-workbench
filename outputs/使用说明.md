# 每日录词工作台 v3

这是一个运行在 macOS 上的本地优先原型应用。正式发布包可内置 Open Dictionary `distribution.sqlite`；首次启动会将它复制到应用支持目录，之后由应用检查官方 Release 更新。它直接读取结构化词性、中文义项、例句和领域标签，再经 AnkiConnect 写入 Anki Deck。详细说明请看仓库根目录 [README.md](../README.md)。

## 快速开始

1. 安装 Anki 与 AnkiConnect，并在 Anki 的 **Tools → Add-ons** 中确认插件已启用。
2. 若你使用含内置词库的正式发布包，直接打开应用；否则从 Open Dictionary Release 下载 `distribution.sqlite.gz`，解压后在设置中选择它。
3. 在本目录运行 `zsh build.sh`，打开生成的「每日录词工作台.app」。
4. 可选：在“设置”的“回退 1：Ollama bge-m3（可选）”分组中检测 Ollama 并下载 `bge-m3`。默认主引擎是它；不可用时回退到本地 cross-encoder（若已安装）或词典标签规则。任何引擎只计算本机相关性，不改写词典内容。
5. 可选：本地 cross-encoder 重排是**候选**主引擎。它需要显式安装约 418 MiB 权重与 llama.cpp 运行时（`zsh ../tools/local-reranker/install-runtime.sh`、`zsh ../tools/local-reranker/download-model.sh`），应用不会自动下载。在真实留出集上它并未优于 `bge-m3`，因此默认链保持不变，详情见 `tools/local-reranker/README.md` 与 `benchmarks/semantic-ranking/results/heldout.benchmark.json`。
6. 新建一个 Anki Deck，再新建 Unit（章节/领域/主题/可选说明），输入单词并在可视化预览中审核后导入 Anki。
7. Anki 的同步功能负责与 AnkiWeb、AnkiDroid 间同步；应用不直接操作云端账号。

## 重要边界

- Unit 的领域/主题/说明只用于义项推荐，不改变 Anki Deck、复习周期或跨设备同步。推荐链为 `Ollama bge-m3 → 本地 cross-encoder（若已安装）→ 词典标签规则`；全部不可用时仍能查词、审核和导入。所有候选义项始终可见，语境不足或置信不足时默认不勾选。
- 未收录词会显示本机拼写候选；你可改正后重查或暂不录入。
- 本地库路径为 `~/Library/Application Support/WordWorkbench/library-v3.json`，不应提交到 GitHub。
- 应用启动时只检查更新元数据；实际更新必须由你在设置中确认。更新会校验 SHA-256 并验证 SQLite，旧词库在失败时保持可用。
- Open Dictionary 数据为 Wiktionary 衍生内容，适用 CC BY-SA 4.0；正式发布包若包含该数据，公开分发时必须附带 [`THIRD_PARTY_DATA.md`](../THIRD_PARTY_DATA.md) 的署名与许可说明。
