# 每日录词工作台 v2

这是一个运行在 macOS 上的本地优先原型应用。它用 Apple Dictionary 作为原始资料源，以本机 Ollama 生成候选卡背，再经 AnkiConnect 写入 Anki Deck。详细的公开说明请看仓库根目录 [README.md](../README.md)。

## 快速开始

1. 安装 Anki 与 AnkiConnect，并在 Anki 的 **Tools → Add-ons** 中确认插件已启用。
2. 安装 Ollama，并准备 `qwen3:8b`；若要使用快速模式，再准备 `qwen2.5:3b`。
3. 在本目录运行 `zsh build.sh`，打开生成的「每日录词工作台.app」。
4. 新建一个 Anki Deck，输入单词，统一整理并审核卡背后导入 Anki。
5. Anki 的同步功能负责与 AnkiWeb、AnkiDroid 间同步；应用不直接操作云端账号。

## 重要边界

- 默认质量模式不截断正文，只剔除 `DERIVATIVES` 与 `ORIGIN`；快速模式的原文上限为 9,000 字符。
- 单词失败会跳过并继续；已成功导入的条目可安全重试。
- 本地库路径为 `~/Library/Application Support/WordWorkbench/library-v2.json`，不应提交到 GitHub。
- 本项目不分发任何词典内容。公开词库前需自行核查来源权利。
